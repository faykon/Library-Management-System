# Library Management System

## About the Project
This is a simple Library Management System created using SQL and SQLite.

The project manages books, library members, and book loans.

## Database Tables

The database contains three tables:

- **Books:** Stores book information.
- **Members:** Stores library member information.
- **Loans:** Stores information about borrowed books.

## SQL Features Used

- CREATE TABLE
- INSERT INTO
- SELECT
- PRIMARY KEY
- FOREIGN KEY
- NOT NULL
- UNIQUE
- CHECK
- JOIN

## Sample Data

The database includes:
